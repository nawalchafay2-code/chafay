# Cabinet RH — Recrutement & Académie V2

## Utilisation
Ouvrir `index.html` dans un navigateur moderne. Aucune installation ou connexion n'est nécessaire.

## Fonctionnalités
- Tableau de bord et pipeline de candidatures.
- CVthèque : fiches, recherche, filtres par domaine, export CSV, suppression confirmée.
- Offres : création, modification du statut, suppression.
- Matching explicable compétences/expérience/domaine (75/20/5), aide humaine uniquement.
- Académie : trois mini-parcours, leçons et quiz avec progression locale.
- Import CSV, détection de doublons, export/restauration JSON.
- Données enregistrées dans le localStorage du navigateur.

## Limites importantes
Ceci est un prototype hors ligne. Il n'a ni comptes utilisateurs, ni serveur sécurisé, ni connexion Gmail, ni analyse automatique de PDF/DOCX, ni facturation, ni certification officielle. Ne pas utiliser pour stocker des CV personnels réels sur un poste partagé. Le navigateur peut effacer ses données ; faire des sauvegardes JSON régulières.

## Étape suivante pour une mise en production
Backend avec base de données, authentification et rôles, consentement/information des candidats, durée de conservation, chiffrement, sauvegardes, audit de sécurité, tests automatisés, hébergement et conformité à la loi marocaine 09-08/CNDP.
